Client defaults

Tri-state defaults for the clients' synced settings. Type in the Key field to search the client's own preference catalog — each hit shows what the setting does, and the value editor follows the key's type (anything not in the catalog is kept as a custom key, for clients newer than this plugin's catalog). Suggested fills only what the user has not set; forced overrides the user. Save writes the map, Push applies it to user accounts (forced always, suggested only where the key is unset).

Custom rows

Home screen rows resolved from external lists. Each row needs a title (shown to clients), a source, an item limit, and the source-specific list identifier (letterboxd username/list slug, IMDb chart or ls-list id, MDBList list id, TMDB list id).

Anime overrides

Map a Jellyfin series to its AniList / MyAnimeList ids, overriding the automatic provider-id derivation for anime markers. Each row needs the series id plus at least one provider id; the optional label is a note for other admins.
